### ⚡ Featured Engineering & Simulation Projects

| Project | Domain | Stack | Highlights |
| :--- | :--- | :--- | :--- |
| **[pulsaRTOS](https://github.com/abominablepug/pulsaRTOS)** | Bare-Metal Real-Time OS | `Rust` `x86_64` `ASM` | Freestanding 64-bit RTOS kernel featuring custom GDT/IDT interrupt handling, APIC timer integration, paging memory management, and a custom heap allocator. |
| **[Magnetohydrodynamic Mayhem](https://github.com/abominablepug/magnetohydrodynamic-mayhem)** | GPU Plasma Simulation | `Rust` `WGSL` `wgpu` `Wasm` | 2D incompressible MHD & plasma simulation on a staggered MAC grid using Semi-Lagrangian advection, Lorentz force coupling, and Jacobi Poisson solvers. |
| **[Boris Particle Pusher](https://github.com/abominablepug/boris-cli)** | Relativistic Astrodynamics | `Rust` `Axum` `React` `Docker` | Electromagnetic charged-particle trajectory integrator using the Boris algorithm, paired with a containerized Rust/Axum + TanStack interactive web runner. |
| **[Turbulent Seas](https://github.com/abominablepug/turbulent-seas)** | Fluid Dynamics | `C++` `Raylib` `Emscripten` | Hybrid particle-grid FLIP fluid simulation compiled to WebAssembly for real-time in-browser execution. |
| **[NEO Tracker API](https://github.com/abominablepug/neo-tracker-api)** | Full-Stack Web & API | `Rust` `Axum` `PostgreSQL` `TanStack` | Near-Earth Object tracking platform integrating NASA's REST API with async SQLx queries, Docker orchestration, and a TanStack Start frontend. |
| **[waybar-wakatime-module](https://github.com/abominablepug/waybar-wakatime-module)** | Linux Desktop Tooling | `Rust` `Waybar` `REST` | Lightweight status bar module supporting Hackatime, WakaTime, and Wakapi with live top-project extraction and custom formatting. |
| **[FRC Team 11104 Robot Code](https://github.com/abominablepug/frc-11104)** | Autonomous Robotics | `Java` `WPILib` `YAGSL` | Swerve drive kinematics, Pigeon 2.0 IMU + CANcoder odometry, AdvantageScope telemetry logging, and autonomous routines for Phoenix Phanatics. |
